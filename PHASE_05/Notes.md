# **1. What is Machine Learning? (ML)**

## **English Definition**

**Machine Learning is a branch of Artificial Intelligence (AI) that enables computers to learn from data, identify patterns, and make predictions or decisions without being explicitly programmed for every task.**

## **Hinglish Definition**

Machine Learning, Artificial Intelligence (AI) ki ek branch hai jisme computer data se learn karta hai, patterns identify karta hai aur predictions ya decisions leta hai, bina har task ke liye manually programming kiye.

### **Example**

Suppose hum computer ko 1,000 spam aur non-spam emails dete hain.

- Computer emails ke patterns learn karega.
- Spam emails ke common features identify karega.
- New email ko analyze karega.
- Predict karega ki email Spam hai ya Ham (Not Spam).

## **A. Supervised Learning**

### **English**

Supervised Learning is a type of ML in which the model learns from labeled data containing both input and correct output.

### **Hinglish**

Supervised Learning mein model ko input ke saath correct output bhi diya jata hai. Model examples se learn karke new data ka output predict karta hai.

### **Example**

| Input         | Output   |
| ------------- | -------- |
| Study 2 hours | 40 marks |
| Study 4 hours | 65 marks |
| Study 6 hours | 85 marks |

Model study hours aur marks ke relationship ko learn karega.

### **Two main types**

**1. Classification**

Classification predicts categories or classes.

Examples:

- Spam / Ham
- Pass / Fail
- Disease / No Disease
- Cat / Dog

**2. Regression**

Regression predicts continuous numerical values.

Examples:

- House price prediction
- Temperature prediction
- Salary prediction
- Sales prediction

### **Important Algorithms**

- Linear Regression
- Logistic Regression
- Decision Tree
- Random Forest
- Support Vector Machine (SVM)
- K-Nearest Neighbors (KNN)
- Naive Bayes

## **B. Unsupervised Learning**

### **English**

Unsupervised Learning is a type of ML in which the model learns patterns and structures from unlabeled data.

### **Hinglish**

Unsupervised Learning mein data ke saath correct output ya label nahi hota. Model khud data ke patterns aur groups identify karta hai.

### **Example: Customer Segmentation**

A company has 1,000 customers.

Machine automatically groups customers according to:

- Shopping behavior
- Spending habits
- Purchase frequency

## **1. Linear Regression**

### **Definition**

Linear Regression is a supervised learning algorithm used to predict continuous numerical values.

### **Hinglish**

Linear Regression input aur output ke beech linear relationship find karta hai aur numerical value predict karta hai.

### **Formula**

\\[ y=mx+c \\]

Where:

- \\(y\\) = Predicted output
- \\(x\\) = Input
- \\(m\\) = Slope
- \\(c\\) = Intercept

## **Important Concepts**

\\[ Mean=\frac{\sum x}{n} \\]

### **Probability**

\\[ P(A)=\frac{\text{Favorable outcomes}}{\text{Total outcomes}} \\]

Data values average se kitni spread hain, measure karta hai.

### **Standard Deviation**

Variance ka square root.

### **Loss Function**

- Mean Squared Error (MSE)
- Cross-Entropy Loss

# **9. Model Evaluation Metrics**

Machine Learning model ko evaluate karna bahut important hai.

## **Classification Metrics**

### **1. Accuracy**

\\[ Accuracy=\frac{Correct\ Predictions}{Total\ Predictions} \\]

Example:

100 emails mein 90 correct predict hue.

Accuracy = 90%

### **2. Precision**

\\[ Precision=\frac{TP}{TP+FP} \\]

Model ne jitne Spam predict kiye, unmein kitne actually Spam the?

### **3. Recall**

\\[ Recall=\frac{TP}{TP+FN} \\]

Actual Spam emails mein se kitne model ne identify kiye?

### **4. F1 Score**

\\[ F1=2\times\frac{Precision\times Recall}{Precision+Recall} \\]

Precision aur Recall ka harmonic mean.

[ml4industry.com](https://www.ml4industry.com/energy/blog/ultimate-machine-learning-cheat-sheet-for-non-specialists?utm_source=chatgpt.com)

## **Overfitting**

English: Model training data ko excessively learn kar leta hai, including noise, but new data par poor performance deta hai.

Hinglish: Model training data ko bahut zyada memorize kar leta hai. Training par achha result aur testing par poor result aa sakta hai.

Example:

- Training accuracy = 99%
- Testing accuracy = 65%

## **Underfitting**

English: Model data ke patterns ko adequately learn nahi kar pata.

Hinglish: Model properly learn nahi karta, isliye training aur testing dono par poor performance aa sakti hai.

Example:

- Training accuracy = 55%
- Testing accuracy = 52%

## **Good Fit**

Model training aur unseen data dono par reasonably good performance deta hai.

### **Overfitting Reduce Karne ke Methods**

- More representative training data
- Regularization
- Cross-validation
- Feature selection
- Pruning in Decision Trees
- Early stopping in applicable models

# **16. Machine Learning Important Interview Questions**

## **Beginner Level**

**Q1. What is Machine Learning?**

Machine Learning is a branch of AI that enables computers to learn from data and make predictions without explicit programming for every task.

**Q2. What are the four types of Machine Learning?**

- Supervised Learning
- Unsupervised Learning
- Reinforcement Learning
- Semi-Supervised Learning

**Q3. What is a dataset?**

A dataset is a collection of data used for training, validation, or testing a machine learning model.

**Q4. What is a feature?**

A feature is an input variable used by a model to make predictions.

**Q5. What is a label?**

A label is the target or correct output associated with training data.

**Q6. What is model training?**

Model training is the process in which an algorithm learns patterns from data.

## **Intermediate Level**

**Q7. Difference between Classification and Regression?**

Classification predicts categories, while Regression predicts continuous numerical values.

**Q8. What is Overfitting?**

Overfitting occurs when a model learns training data excessively and performs poorly on unseen data.

**Q9. What is Underfitting?**

Underfitting occurs when a model fails to learn important patterns from data.

**Q10. What is Cross-Validation?**

Cross-validation is a technique for evaluating model performance using multiple data splits.

**Q11. What is Feature Engineering?**

Feature engineering is the process of creating, transforming, or selecting useful input features for a model.

**Q12. What is Hyperparameter Tuning?**

Hyperparameter tuning is the process of selecting suitable training configurations to improve model performance.

## **Advanced Level**

**Q13. What is Gradient Descent?**

Gradient Descent is an optimization algorithm that updates model parameters to minimize a loss function.

**Q14. What is Regularization?**

Regularization adds a penalty to model complexity to help reduce overfitting.

**Q15. What is Data Leakage?**

Data leakage occurs when information unavailable at prediction time incorrectly enters model training or evaluation, leading to overly optimistic results.

**Q16. What is Bias-Variance Tradeoff?**

It describes balancing errors due to overly simple assumptions (bias) and excessive sensitivity to training data (variance).
